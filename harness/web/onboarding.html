Choose the operating system of the computer that will run FreeCAD, OpenSCAD and SearXNG. Keep Docker running while you work.

Install Docker Engine with Compose, Git and curl. Run your command in a terminal.

Your command pulls CAD-Pilot from GitHub, builds the CAD image and starts SearXNG.

Run in your Linux terminal:





The first build downloads several GB and may take a while. Your computer connects to this account automatically; no incoming port or extra tunnel is needed. CAD runs as Linux x86-64, including through Docker Desktop's amd64 support.


Reconnect or replace a computer
Generating a new command revokes the previous connection. Rerun it on the same computer to update the source and keep your saved projects. The code is private, works once, and expires after 24 hours.


For a setup without Git, download and extract a ZIP, then run docker compose up -d --build --wait in that folder. This also replaces your current pairing code.
